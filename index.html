使用说明 / 常见问题
1. 令牌从哪来：GitHub → 头像 → Settings → Developer settings → Personal access tokens → Tokens(classic)，勾选 repo 权限生成 ghp_ 开头的令牌。令牌只保存在你浏览器输入框，页面不会存盘或外传，仅用于调用 GitHub API 写文件。
2. 没令牌也能用：可直接编辑仓库里的 keepalive.json 后提交，效果一样。本地 keepalive_studios.py 也读同一份配置。
3. 为什么不部署成在线服务：保活需要持久运行的进程，本地定时会随机关机中断；改用 GitHub Actions 云端定时，不依赖你的电脑。
4. 状态判断：200=在线保温；404/502=已发唤醒信号，1-2分钟自动启动；401/403=需手动点平台「发布」。
5. 查看运行记录：仓库 Actions 标签页可看每次保活日志；keepalive.log 有最近结果。
